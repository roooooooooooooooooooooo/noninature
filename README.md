# NoniNature (নোনি নেচার) — সম্পূর্ণ ই-কমার্স প্ল্যাটফর্ম গাইড

স্বাগতম **NoniNature (নোনি নেচার)** ই-কমার্স প্রজেক্টে! এটি বাংলাদেশের বাজারে ১০০% খাঁটি অর্গানিক নোনি ফল, কোল্ড-প্রেসড নোনি জুস, রোদে শুকানো নোনি স্লাইস, কলম চারা গাছ এবং ভেষজ স্কিনকেয়ার পণ্যের একটি সম্পূর্ণ ও আধুনিক ই-কমার্স প্ল্যাটফর্ম।

আপনি যদি একজন নতুন প্রোগ্রামার (beginner) হন, তবে নিচের সহজ বাংলা নির্দেশিকা অনুসরণ করে প্রজেক্টটি খুব সহজেই নিজের কম্পিউটারে চালাতে পারবেন এবং Supabase ডাটাবেসের সাথে সংযুক্ত করতে পারবেন।

---

## ১. প্রয়োজনীয় সফটওয়্যার ইনস্টলেশন (Prerequisites)

আপনার কম্পিউটারে নিচের সফটওয়্যারগুলো ইন্সটল থাকতে হবে:
1. **Node.js (LTS সংস্করণ):** [nodejs.org](https://nodejs.org) থেকে LTS সংস্করণ (v20 বা v22/v24) ডাউনলোড করে ইন্সটল করুন।
2. **VS Code (কোড এডিটর):** [code.visualstudio.com](https://code.visualstudio.com)
3. **Git (ভার্সন কন্ট্রোল):** [git-scm.com](https://git-scm.com)
4. **প্যাকেজ ম্যানেজার:** `npm` (Node.js এর সাথে বিল্ট-ইন থাকে) অথবা `pnpm`।

---

## ২. অ্যাপটি লোকাল কম্পিউটারে রান করার পদ্ধতি (Local Setup)

টার্মিনাল বা PowerShell ওপেন করে প্রজেক্ট ফোল্ডারে প্রবেশ করুন এবং নিচের কমান্ডগুলো দিন:

```bash
# ডিপেন্ডেন্সি প্যাকেজ ইন্সটল করুন
npm install
# অথবা
pnpm install

# ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev
# অথবা
pnpm run dev
```

এবার আপনার ব্রাউজারে প্রবেশ করুন: **[http://localhost:3000](http://localhost:3000)**

---

## ৩. Supabase প্রোজেক্ট তৈরি করার নিয়ম (Supabase Setup)

1. [supabase.com](https://supabase.com) এ গিয়ে একটি ফ্রি একাউন্ট খুলুন।
2. **"New Project"** বোতামে ক্লিক করুন।
3. আপনার প্রোজেক্টের নাম দিন (যেমন: `noninature-db`) এবং একটি শক্তিশালী ডাটাবেস পাসওয়ার্ড দিন।
4. Region হিসেবে **"Singapore"** অথবা নিকটবর্তী এশিয়ান রিজিওন নির্বাচন করুন এবং **"Create new project"** চাপুন।

---

## ৪. এনভায়রনমেন্ট ভেরিয়েবল কনফিগারেশন (.env.local)

প্রজেক্টের মূল ফোল্ডারে `.env.example` ফাইলটির একটি কপি তৈরি করে নাম দিন `.env.local`:

```env
# Supabase পাবলিক ক্রেডেনশিয়ালস (ব্রাউজারের জন্য নিরাপদ)
NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

# Supabase সার্ভার-অনলি সিক্রেট কী (কখনও ব্রাউজারে প্রকাশ করবেন না)
SUPABASE_SERVICE_ROLE_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

# অ্যাপ্লিকেশনের বেস URL
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```

> **কোথা থেকে কী পাবেন?**
> Supabase ড্যাশবোর্ডে গিয়ে **Project Settings -> API** সেকশনে আপনার `Project URL`, `anon public` কী এবং `service_role secret` কী পেয়ে যাবেন।

## ৫. ডাটাবেস মাইগ্রেশন প্রয়োগ করার পদ্ধতি (Apply SQL Migrations)

প্রজেক্টে ইতিমধ্যেই সম্পূর্ণ টেস্টেড PostgreSQL স্কিমা এবং আরএলএস (Row Level Security) পলিসি প্রস্তুত করা আছে।

1. Supabase ড্যাশবোর্ডের বাম পাশের মেনু থেকে **"SQL Editor"** এ যান।
2. **"New query"** বোতামে ক্লিক করুন।
3. প্রজেক্টের `supabase/migrations/20261026_init_schema.sql` ফাইলের সমস্ত কোড কপি করে SQL Editor এ পেস্ট করে **"Run"** চাপুন।
4. একইভাবে নমুনা পণ্যের ডাটা যোগ করতে `supabase/seed.sql` ফাইলের কোড কপি করে পেস্ট করে **"Run"** চাপুন।

---

## ৬. অথেনটিকেশন URL কনফিগারেশন (Auth URLs)

1. Supabase ড্যাশবোর্ডে **Authentication -> URL Configuration** এ যান।
2. **Site URL** হিসেবে দিন: `http://localhost:3000` (প্রোডাকশনের ক্ষেত্রে আপনার ডোমেইন)।
3. **Redirect URLs** এ যোগ করুন:
   - `http://localhost:3000/**`
   - `http://localhost:3000/auth/callback`

---

## ৭. Supabase Storage কনফিগারেশন (Image Storage)

পণ্যের ছবি এবং স্লাইডার ছবি আপলোডের জন্য:
1. Supabase ড্যাশবোর্ডে **Storage** সেকশনে যান।
2. **"New Bucket"** এ ক্লিক করে একটি বাকেটের নাম দিন: `products` (Public Bucket অপশনটি চালু রাখুন)।
3. একইভাবে আরেকটি বাকেট খুলুন: `slides`।

## ৮. প্রথম এডমিন একাউন্ট নিরাপদে তৈরি করার পদ্ধতি (First Admin Setup)

নিরাপত্তার স্বার্থে পাবলিক রেজিস্ট্রেশনের মাধ্যমে সরাসরি কোনো এডমিন একাউন্ট তৈরি করা যায় না। প্রথম এডমিন তৈরির সঠিক নিয়ম:

1. প্রথমে ওয়েবসাইটের `/register` পৃষ্ঠায় গিয়ে আপনার নিজস্ব ইমেইল (যেমন: `admin@noninature.com`) দিয়ে একটি সাধারণ একাউন্ট রেজিস্টার করুন।
2. এরপর Supabase ড্যাশবোর্ডের **Table Editor** এ যান এবং `profiles` টেবিলে ক্লিক করুন।
3. আপনার ইমেইলের সারির `role` কলামে গিয়ে `customer` পরিবর্তন করে লিখুন: `admin` এবং সেভ করুন।
4. এখন ওই ইমেইল দিয়ে লগইন করলে আপনি স্বয়ংক্রিয়ভাবে সম্পূর্ণ `/admin` ড্যাশবোর্ডের নিয়ন্ত্রণ পেয়ে যাবেন!

*(দ্রষ্টব্য: লোকাল ডেভেলপমেন্ট ও টেস্টের সুবিধার্থে লগইন পেজে একটি তাৎক্ষণিক "Admin Demo Access" বাটন যুক্ত রয়েছে, যা ডাটাবেস ছাড়াও তাৎক্ষণিক ড্যাশবোর্ড পরীক্ষার সুযোগ দেয়।)*

## ৯. ডেলিভারি ও পেমেন্ট সেটিংস কনফিগারেশন (Delivery & Payments)

ওয়েবসাইটের এডমিন প্যানেলের **Settings (`/admin/settings`)** থেকে আপনি যেকোনো সময়:
- **ডেলিভারি চার্জ:** ঢাকার ভেতরে (Inside Dhaka), ঢাকার বাইরে (Outside Dhaka) বা নির্দিষ্ট জেলার ডেলিভারি চার্জ পরিবর্তন করতে পারবেন।
- **ফ্রি ডেলিভারি:** ২,০০০ টাকা বা আপনার পছন্দমত নূন্যতম অর্ডারে ফ্রি ডেলিভারি সীমা নির্ধারণ করতে পারবেন।
- **মোবাইল ব্যাংকিং:** বিকাশ, নগদ ও রকেট পার্সোনাল নম্বর, ক্যাশ অন ডেলিভারি এবং ব্যাংক একাউন্ট নম্বর ও বাংলা-ইংরেজি নির্দেশিকা আপডেট করতে পারবেন।

## ১০. অটোমেটেড টেস্ট এবং ডিপ্লয়মেন্ট (Tests & Deployment)

### অটোমেটেড টেস্ট রান করুন:
```bash
npm test
# অথবা
pnpm test
```
*(এই টেস্টটি বাংলাদেশের মোবাইল নম্বর ফরম্যাট ভ্যালিডেশন, ফ্রি ডেলিভারি হিসাব, পণ্যের মূল্য ও ভ্যারিয়েশন এবং স্টক ইনভেরিয়েন্ট যাচাই করে।)*

### প্রোডাকশন বিল্ড তৈরি করুন:
```bash
npm run build
# অথবা
pnpm run build
```

### লাইভ ডিপ্লয়মেন্ট:
এই Next.js অ্যাপ্লিকেশনটি [Vercel](https://vercel.com) অথবা [Netlify](https://netlify.com) এ এক ক্লিকে ডিপ্লয় করা যায়। রিপোজিটরিটি কানেক্ট করে Environment Variables সেকশনে আপনার Supabase এর কীগুলো সেট করে দিলেই সম্পূর্ণ লাইভ চালু হয়ে যাবে।
